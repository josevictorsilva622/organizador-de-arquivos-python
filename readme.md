# Organizador de Arquivos em Python

Projeto desenvolvido para organizar arquivos automaticamente por tipo.

## Funcionalidades
- Separa arquivos por categoria (PDF, imagens, documentos, etc.)
- Cria pastas automaticamente
- Organiza arquivos de forma prática

## Tecnologias utilizadas
- Python

## Como usar
1. Defina o caminho da pasta no código
2. Execute o script
3. Os arquivos serão organizados automaticamente
